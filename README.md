# ShopEase 
ShopEase — E-commerce web application built with Spring Boot, Thymeleaf, and MySQL. Features product browsing, search, shopping cart, and order management with role-based access control.   

# Mysql

When you need to start MySQL, open Command Prompt as Administrator and run:

```bash
net start MySQL80
```
That's it. To stop it later:

````bash
net stop MYSQL80
````
Log in as root
````bash
mysql -u root -p
````
